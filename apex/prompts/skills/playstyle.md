# 标的玩法判定方法论

> 玩法 = **这只股票本身适合怎么玩**（客观属性），不是"最近涨跌/当前趋势"。
> 下行期的资源周期股仍是波段；景气暂时下滑的龙头仍是中线。别用当前 K 线方向覆盖股票属性。

## 1. 四档玩法定义

| 玩法 | 定义 | 典型持仓周期 |
|------|------|------------|
| **打野** | 题材驱动、游资主导、持续性差，快进快出。ST/重组/摘帽/纯情绪票。 | 当日-2天 |
| **波段** | 有产业逻辑但波动大，做趋势/周期轮动。资源/面板/主题科技。 | 20-60天 |
| **中线** | 行业龙头，基本面驱动，一轮景气周期。 | 3-12月 |
| **长线** | 商业模式成熟、ROE 稳定、竞争优势强（护城河），长期持有。 | 季以上 |

无法明确归类 -> 取最接近的两档作 Primary + Secondary，仍不明确则 Primary 取属性最强的，Secondary 留空。

## 2. 识别特征（FE 特征 + 定性判断）

玩法特征（Playstyle FE）已注入 prompt（## 玩法特征 段）。**FE 是数字证据，定性维度靠你 + web_search**：

| 玩法 | FE 数字证据 | 定性维度（web_search / 推理） |
|------|-----------|--------------------------|
| 打野 | 连板高度、涨停次数、换手>10% | 题材龙头、游资属性、ST/重组/摘帽事件 |
| 波段 | MA 排列、主力净流入、波动率、换手 | 产业逻辑、资源/周期属性、主题驱动 |
| 中线 | or_yoy、PE、ROE | 行业景气、龙头地位、景气周期位置 |
| 长线 | or_yoy 持续、ROE 稳定、估值水位 | 商业模式、护城河、现金流、分红、竞争格局 |

> **题材龙头 / 行业景气 / 商业模式 / 护城河 不是 FE 数字**，必须引用 web_search 结果（如"行业景气(光伏排产+20% 博查结果)"、"护城河(全球安防龙头 市占率40%)")，禁凭空编。

## 3. 星级 rubric（0-5，v1 初值待校准）

| 玩法 | 5★ | 3★ | 1★ |
|------|-----|-----|-----|
| 打野 | 连板≥3 + 换手>15% + 题材龙头 | 连板1-2 + 换手>10% | 无连板 + 换手<5% |
| 波段 | MA 多头完整 + 主力连续5日正 + 波动适中 | MA 部分多头 + 主力净流入正 | MA 空头 + 主力净流出 |
| 中线 | or_yoy>20% + 行业景气 + 估值合理 | or_yoy>10% + 基本面平稳 | or_yoy<5% 或持续下滑 |
| 长线 | 商业模式成熟 + ROE 稳定高 + 估值合理 | 基本面稳健 + 估值中性 | 业绩持续下滑 + 估值高位 |

**打野/中线的 5★ 锚点含定性维度（题材龙头/行业景气），你判得到就给 5★，判不到就封顶 4★**（别为凑 5★ 编题材龙头）。波段/长线 5★ 全 FE+定性可达。

## 4. Primary + Secondary（主玩法 + 兼容玩法）

很多股票不止一种玩法。给 **Primary（主玩法）+ Secondary（兼容玩法）**：

- Primary = 最高星玩法（必须 = ratings 的并列最高，见 §6）。
- Secondary = 次优或可替代玩法（次高星，或你判断可兼容的）。无兼容则留空。
- 例：工业富联 Primary=中线(景气周期) Secondary=波段(制造业波动)；海康 Primary=长线 Secondary=中线。

这样下游可结合用户画像灵活推荐（稳健用户走 Primary，趋势用户走 Secondary）。

## 5. 核心判断纪律（勿犯）

1. **玩法 = 股票属性，非当前趋势。** 下行期的周期股仍是波段（你做它的周期，不是它的趋势方向）。MA 空头排列不等于"不是波段"。
2. **长线看商业模式，不是单看增速。** 中等增速(10-15%)+稳定 ROE+成熟商业模式+合理估值 = 长线（如安防/食品饮料龙头）。别因 or_yoy 没到 15% 就拒判长线。
3. **周期性下滑 ≠ 结构性恶化。** 龙头因行业周期单季 -10% 仍是中线/长线；只有**多季持续下滑+份额丢失**才是结构性恶化。别因单季 or_yoy 为负就把中线压到 1★。
4. **ST / 重组 / 摘帽 = 打野。** 事件驱动、情绪主导，不看基本面。ST 票即使 PE 低也别判长线。
5. **资源/周期股 = 波段。** 锂、面板、化工、油价的利润弹性大，做周期波段，不是长线持有。

## 6. record_verdict 填法 + 一致性校验

调 record_verdict 时填 `playstyle`（FE 完整度 ≥50% 时必填，<50% 允许 null）：

```
playstyle: {
  ratings: {打野: 0-5, 波段: 0-5, 中线: 0-5, 长线: 0-5},
  primary: "长线",            # 必须是 ratings 的并列最高（tied-for-max）
  secondary: "中线",          # 次优或兼容，无则留空
  reasons: ["护城河(全球安防龙头 市占率40% web_search)", "ROE稳定(近4季全正 FE)", "商业模式成熟(现金流优秀 web_search)"]
}
```

**一致性（系统强制）**：
- `primary` 必须 = `ratings` 的并列最高（ratings[primary] == max）。不符合系统会自动改成 argmax，但你应主动对齐。
- `primary=长线` 但 60日波动率>80% **且** 业绩多季持续弱（or_yoy 多季<15% 或 fundamentals 缺）-> 系统标记低置信（高波动+无业绩支撑 ≠ 长线），请重判。

**原因必须可追溯**：每条引用 FE 特征数字 或 web_search 具体结果，禁凭空编。格式："维度(FE数字 或 web_search 结果)"。

## 7. 案例（基准集实测）

- **海康威视(002415) -> 长线/中线**：全球安防龙头，商业模式成熟，现金流/分红稳定，AI/机器视觉新增长。or_yoy 11.8%/PE 20/ROE 稳定 -> 长线（中等增速+护城河，非高增速长线）。别因 MA 多头就判波段。
- **比亚迪(002594) -> 中线/波段**：新能源龙头但行业竞争/技术迭代快，每隔几年重新估值，景气周期属性。单季 or_yoy -11.8% 是周期波动，仍中线，别压至 1★。
- **中矿资源(002738) -> 波段/中线**：锂资源周期股，商品价格决定利润弹性，两三倍上涨/腰斩下跌。下行期仍是波段（做周期，非趋势方向）。
- **ST京机(000821) -> 打野**：ST 重组/摘帽预期，事件驱动+游资，不看 -47% 业绩，直接打野。

## 8. chat 侧用法（仅 chat）

用户问"这票适合怎么玩 / 该拿多久"时：调 `get_stock_analysis(ts_code, detail=full)` 拿 verdict + `playstyle`，对照本规则解释 Primary/Secondary + 原因。不臆造未在 evidence/FE 出现的数字。
