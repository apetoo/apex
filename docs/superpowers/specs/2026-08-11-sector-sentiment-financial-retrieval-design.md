# 板块情绪金融检索与财经作者池设计

## 目标

解决板块裸关键词在短视频平台召回大量非金融内容的问题。系统通过“金融组合关键词搜索＋已审核财经作者池”获得投资语境内容，再进入现有板块映射、情绪分类和两层预警流程。

首版仍为个人研究和影子运行，不影响选股、仓位或自动交易。

## 检索策略

板块词典除 `sector_id`、名称和别名外，增加版本化的检索配置。系统不得直接用通用实体裸词搜索，而是通过模板生成组合查询：

- `{板块或别名} 股票`
- `{板块或别名} A股`
- `{板块或别名} 板块`
- `{板块或别名} 概念股`
- `{板块或别名} ETF`
- `{板块或别名} 龙头`
- `{板块或别名} 投资`
- `{板块或别名} 行情`

每个板块每日查询数量、每个查询抓取内容数和评论数均设上限。相同查询、内容和评论继续使用现有批次记录及幂等去重。

## 金融语境门槛

内容在板块情绪分类之前先计算 `financial_relevance`，输出 `score`、`decision` 和可审计的 `reasons`。

正向金融证据包括股票、A股、板块、概念股、ETF、行情、主力、资金、涨停、估值、持仓、加仓、减仓等。排除证据包括教程、编程、机械臂安装、产品测评、比赛和玩具等纯技术或物理语境。

标题、简介和标签的权重高于评论。满足以下任一条件才进入情绪聚合：

- 标题、简介或标签包含板块实体，同时包含明确金融证据；
- 内容来自已批准财经作者，且正文或评论存在投资语境；
- 低置信规则结果经固定版本LLM判断为金融相关。

未通过的内容继续保留在原始数据中，但标记 `filtered_non_financial`，不得影响情绪、作者统计或预警。

## 财经作者池

作者记录使用平台和平台作者ID作为稳定主键，保存显示名、状态、首次/最近发现时间、金融内容比例、命中板块、证据样例和审核时间，不保存登录凭证。

状态包括：

- `candidate`：系统发现，等待人工审核。
- `approved`：每日通过 MediaCrawler `creator` 模式抓取新内容。
- `rejected`：营销号、搬运号或非财经作者；不再自动重复推荐，允许人工恢复。

满足以下任一条件时创建候选作者：

- 累计至少3条通过金融语境门槛的内容；
- 单条内容金融相关置信度很高且互动达到平台配置门槛；
- 被至少两个不同板块的金融组合查询命中。

候选作者不能自动升级为 `approved`。批准和拒绝操作必须写入审计事件，并只影响后续采集，不回写历史评分。

## 数据流与故障处理

每日盘后执行顺序：

1. 为行业和概念板块生成有配额的金融组合查询。
2. 通过 MediaCrawler `search` 模式抓取内容与评论。
3. 标准化、去重并计算金融语境相关性。
4. 更新候选作者统计。
5. 通过 MediaCrawler `creator` 模式抓取已批准作者的新内容。
6. 合并去重后进入现有板块映射、语义证据、聚合评分和状态机。

搜索采集和作者采集分别记录覆盖率。某个平台或某个作者失败时只降低对应覆盖率，不中断其他来源。作者ID失效时保留作者记录并标记采集错误，不自动删除或改为拒绝。

## API 与页面

新增接口：

- `GET /api/sector-sentiment/creators?status=`：查询候选、已批准或已拒绝作者。
- `POST /api/sector-sentiment/creators/{platform}/{creator_id}/approve`：批准作者。
- `POST /api/sector-sentiment/creators/{platform}/{creator_id}/reject`：拒绝作者。
- `POST /api/sector-sentiment/creators/{platform}/{creator_id}/restore`：恢复为候选。

“情绪预警”页面增加“作者池”视图，显示平台、作者名、金融内容比例、有效内容数、命中板块、最近发现时间和脱敏样例。候选列表支持批准和拒绝，已批准/已拒绝列表支持状态变更。

板块详情增加数据漏斗：原始召回数、金融相关数、过滤数、搜索来源数和作者池来源数，方便识别关键词污染或作者池偏置。

## 测试与验收

- `机器人`产品测评、机械臂教程等内容必须被过滤；“机器人板块资金流入、继续看多”等内容必须通过。
- 组合查询必须包含金融锚点，不能产生裸的通用实体查询。
- 同一作者满足候选条件时只创建一条记录；重复运行不重复累计相同内容。
- 候选作者不能未经人工操作进入已批准状态。
- 批准后只抓取后续内容；拒绝后停止作者定向采集；恢复后重新进入候选状态。
- 单作者、单平台失败不阻断当日其他采集任务，并正确降低覆盖率。
- 被过滤内容保留原始记录和原因，但不进入情绪聚合。
- 页面正确处理空作者池、低覆盖、审核操作失败和已失效作者。

## 边界与默认值

- 首版只覆盖当前配置的B站、抖音以及后续接入的财经社区。
- 首版不根据粉丝数自动判断财经作者，不把大V身份当作观点质量。
- 不抓取或展示作者个人敏感信息；页面只使用平台公开显示信息。
- 作者池是召回来源，不直接增加情绪权重；搜索内容和作者内容仍按平台等权及转载降权规则聚合。
- 金融语境词典、查询模板、LLM提示词和作者规则均保存版本号，60日验证期内冻结版本。
