# 持仓报告 Ladder 规范化设计

## 背景

000977.SZ 的结构化持仓计划包含一个全部退出档：`trim pct=1.0, new_stop=0`。全部退出后不存在新止损，但正式报告校验要求逐字出现“新止损 0”，导致报告合理省略该字段时被判为“条件触发计划与结构化结果不一致”。独立复核已经通过，本次失败发生在正式报告生成与确定性校验之间。

## 目标

- 全部退出档中的 `new_stop<=0` 统一视为无新止损，即 `None`。
- `scale_plan` 报告格式只在新止损有效时要求“新止损 <value>”。
- 保持有效正数新止损、触发价、股数/比例、档位顺序的严格一致性校验。
- 校验失败时输出可定位的期望值与解析值摘要。

## 方案

在正式报告生成前规范化 position-action candidate：对 `action=trim` 且 `pct=1.0` 的档位，如果 `new_stop` 缺失、为零或为负，则复制该档并把 `new_stop` 设为 `None`。不修改部分减仓、加仓档或任何正数新止损。

报告合同改为两种合法格式：

```text
- trim @ 71.5，比例 1.0
- add @ 79.0，100 股，新止损 73.0
```

报告解析器继续把省略的新止损解析为 `None`，并与规范化后的 candidate 比较。若不一致，错误信息增加压缩后的 `expected` 与 `parsed`，但不包含研究正文或敏感信息。

## 错误处理

- 非对象档位、同时存在/同时缺失 `shares` 与 `pct` 等既有结构错误继续阻断。
- 部分减仓的 `new_stop=0` 不自动吞掉，仍按原有结构校验处理，避免掩盖错误计划。
- 自然语言 ladder 仍不被接受；正式报告必须使用机器可解析的标准 bullet。

## 测试

- 复现 000977：全部退出档 `new_stop=0`，报告省略该字段时校验通过。
- 同一计划的加仓档仍必须精确匹配 `new_stop=73.0`。
- 部分减仓或正数新止损不被规范化。
- 真正的 trigger、比例、股数、动作或正数新止损差异继续失败。
- 失败信息包含 expected/parsed 摘要。
- 完整 `tests/test_analysis_graph.py` 通过。

## 非目标

- 不放宽自然语言报告解析。
- 不改变交易计划业务校验、独立复核或证据门控。
- 不重新运行或覆盖已经失败的 000977 journal 记录；修复对后续分析生效。
