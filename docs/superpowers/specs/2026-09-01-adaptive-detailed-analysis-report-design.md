# 自适应详细分析报告设计

## 背景

当前分析链路会先产生研究过程与候选草稿，再经过确定性证据裁决、独立复核和正式报告生成。正式报告可靠，但相较研究步骤会遗漏部分已经存在于权威系统上下文中的有用信息，例如市场环境、历史判断复盘、玩法定位、未知项与证据取舍。

600487.SH 的最新分析体现了这一问题：最终报告正确使用了三条后端计入证据，但没有解释历史判断修正、市场“亢奋/高潮”环境、后端玩法定位，以及龙虎榜证据为何因时间口径未被计入。

## 目标

- 在不降低分析准确度的前提下，提高正式报告的信息完整度与解释力。
- 根据权威数据是否存在，自适应生成相关章节；不为填满格式而编造内容。
- 让用户能区分已计入方向裁决的证据、仅用于背景解释的系统上下文、被排除的证据与仍未知的数据。
- 保持页面现有渲染方式，继续完整展示 `analysis_text`。

## 准确度硬约束

以下现有机制不放宽：

- 最终方向仍由后端确定性决策策略计算。
- `confirmed_evidence` 仍是正式多空论点的唯一证据来源。
- 证据覆盖率、净硬度、置信度、证据 ID 和交易计划继续执行严格一致性校验。
- 独立复核继续发生在正式报告生成之前。
- 研究步骤中的临时草稿、未收录事实和模型自行计算结果不得进入正式报告。
- 被排除的证据只能用于说明“为何未计入”，不得作为方向或硬度依据。

## 权威报告上下文

正式报告节点在现有 `confirmed_evidence`、`decision_policy`、`stock_profile` 和 `calibration` 基础上，增加经过裁剪的只读上下文：

### 市场与个股环境

来源仅限后端预计算的市场、分时与玩法特征摘要，包括市场 regime、市场风格、指数环境、相对强弱、已完成分时特征及四维系统指标。原始工具对话不作为该章节的权威输入。

### 历史判断复盘

来源仅限 journal 历史摘要中的真实 verdict、置信度、前向结果或实盘结果。报告可以解释历史错误与本次修正，但不得把历史收益当作当前方向证据。

### 玩法与适用周期

来源仅限后端最终 `playstyle`、`playstyle_features`、`playstyle_fit`、`risk_level` 和股票软分类。模型不得自行重新分类或根据叙述另算星级。

### 证据取舍

来源仅限 `decision_policy.counted_claims` 与 `decision_policy.excluded_claims`。报告必须明确区分：计入裁决、因过期/重复/不完整等原因排除，以及未知项。

### 未知项

来源仅限分析状态中的 `unknowns` 与经过后端确认的数据缺口。缺失数据只能标记为未知，不得用搜索摘要或模型常识补齐。

所有新增上下文都采用白名单字段与长度上限，避免把完整 trace、原始对话或未受控数据重新注入正式报告。

## 自适应章节契约

正式 verdict 报告保留现有章节，并扩展为：

1. `## 核心判断`
2. `## 基本面分析`
3. `## 市场与个股环境`
4. `## 四维分析`
5. `## 一、多头论点`
6. `## 二、空头论点`
7. `## 三、裁判结论`
8. `### 加权四维评分`
9. `### 证据取舍与冲突`
10. `### 历史判断复盘`
11. `### 玩法与适用周期`
12. `### 置信度调整`
13. `## 操作建议`
14. `## 风险与未知项`

自适应规则：

- 核心判断、多空论点、裁判结论、评分、置信度、操作建议与风险章节始终存在。
- 市场、历史复盘、玩法、证据取舍章节在对应权威上下文存在时详细输出。
- 对应上下文不存在时，章节保留一条简短的“本次无可靠数据/无历史样本”，不允许模型自行补充。
- 目标长度通常为 2000–3000 个中文字符，但完整性与准确度优先；不得为达到长度添加未验证事实。

## 数据流

`研究与工具调用 → 证据控制器 → 确定性方向裁决 → 独立复核 → 构造白名单权威报告上下文 → 生成自适应详细报告 → 严格一致性校验 → journal / 页面展示`

## 前端影响

不修改前端组件。`VerdictDetailCard` 已使用 Markdown 完整渲染 `analysis_text`，分析页和 journal 详情会自动展示扩充后的正式报告。

## 测试策略

### 权威上下文测试

- 新增上下文只包含允许的白名单字段。
- 原始 trace、研究草稿和未计入证据不会进入正式报告提示。
- 历史、市场和玩法数据缺失时生成明确的空态上下文。

### 报告契约测试

- 权威上下文齐全时，正式报告包含新增章节。
- 上下文缺失时，允许章节显示简短未知说明，不要求模型编造细节。
- 被排除证据不得出现在多空论点的 evidence ID 列表中。
- 新章节不能改变结构化 verdict、confidence、coverage、net hardness 与 price advice。

### 回归测试

- 现有报告校验测试全部继续通过。
- 持仓 `position_action` 报告格式保持不变。
- 以类似 600487 的 fixture 验证：历史复盘、市场 regime、玩法定位和排除原因进入正式报告上下文，但未确认的现金流、PEG、负债率等研究草稿事实不会进入。

## 非目标

- 不把详细步骤或 trace 直接复制到正式报告。
- 不修改搜索策略、证据评分、方向阈值、置信度校准或交易建议算法。
- 不修改前端布局与交互。
- 不回写或重生成既有 journal 记录。
