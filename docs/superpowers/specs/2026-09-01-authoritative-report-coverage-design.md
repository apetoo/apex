# 正式报告证据覆盖率权威写入设计

## 背景

股票分析的结构化裁决由后端计算 `evidence_coverage`，正式报告目前要求模型把该值转换为百分比并写成 `**证据覆盖率：X%**`。模型一旦遗漏、重复或抄错该字段，严格校验就会拒绝整份报告。002156.SZ 已连续三次在这一阶段失败，搜索和证据收集本身正常。

## 目标

- 后端计算结果是证据覆盖率的唯一事实来源。
- 正式报告恰好包含一个规范字段：`**证据覆盖率：X%**`。
- 模型对该字段的遗漏、误写或重复不再导致一次完整分析作废。
- 其他正式报告契约继续严格校验，包括判断、置信度、净硬度、证据 ID、章节和交易计划。

## 方案

报告节点收到模型正文后，在最终校验之前执行一次确定性规范化：

1. 从结构化候选结果读取 `evidence_coverage`，按现有规则乘以 100 并保留一位小数。
2. 删除正文中模型生成的所有粗体 `证据覆盖率` 字段。
3. 在“裁判结论”约定位置写入唯一的权威字段。
4. 对规范化后的报告运行现有严格校验。

模型提示仍明确该字段由系统提供，避免模型围绕覆盖率另算一套数字。规范化只处理带明确标签的覆盖率字段，不改写普通分析文字，也不放宽其他冲突检测。

## 数据流

`结构化裁决 → 模型报告草稿 → 后端覆盖率规范化 → 严格报告校验 → 保存正式报告`

## 错误处理与可观测性

- 结构化结果没有 `evidence_coverage` 时，不注入字段，沿用现有校验语义。
- 如果报告缺少可插入的“裁判结论”章节，规范化不掩盖问题，章节校验仍然失败。
- 报告最终仍失败时，在结果中保留报告校验问题；本次改动不改变失败状态或重试预算。

## 测试

采用测试优先：

1. 模型遗漏覆盖率字段时，规范化后插入唯一正确值。
2. 模型写错覆盖率时，错误值被权威值替换。
3. 模型重复写入不同覆盖率时，规范化后只剩一个权威值。
4. 规范化报告通过覆盖率一致性校验。
5. 缺少必需章节及其他字段冲突仍被原校验器拒绝。

## 非目标

- 不修改博查搜索、证据筛选、覆盖率算法或方向裁决。
- 不放宽来源等级、实体匹配、证据 ID 或报告其他数值字段的校验。
- 不重新生成既有失败的 journal 记录。
